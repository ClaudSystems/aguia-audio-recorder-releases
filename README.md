# 🦅 Águia Audio Recorder — Releases

Distribuição oficial do **Águia Audio Recorder** — aplicação desktop para gravação de áudio do sistema com corte automático por silêncio.

## 📥 Download

A versão mais recente está disponível na [página de Releases](https://github.com/ClaudSystems/aguia-audio-recorder-releases/releases).

## 🎯 Funcionalidades

- 🎙️ Gravação de áudio do sistema (Stereo Mix / Loopback)
- ✂️ Corte automático por silêncio
- ⏸️ Auto-stop por silêncio (pausa no modo contínuo)
- 🎵 Player integrado
- 🌍 5 idiomas (PT, EN, ES, FR, ZH)
- 📊 VU meter de precisão

## 💰 Preços

- **Free** — funcionalidades básicas com anúncios
- **Pro ($2.99)** — sem anúncios, corte automático inteligente
- **Pagamento:** M-Pesa, eMola, LemonSqueezy
